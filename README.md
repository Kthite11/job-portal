# job-portal
A dynamic and responsive Job Portal web application built using Java, JSP, MySQL, and modern front-end technologies. This project allows users to search and apply for jobs, while providing administrators with full control over job postings and user management. 
 Features
🔐 Role-Based Authentication – Separate login for Admin and User with secure session handling

📋 Job Listings – Post, update, delete, and manage job listings with full CRUD operations

🔎 Smart Job Search – Filter jobs by category, location, and keywords

👤 User Dashboard – Track applications, manage profile, and view job history

📱 Responsive UI – Interactive and mobile-friendly design using HTML, CSS Flexbox/Grid, and JavaScript

🛠️ Technologies Used
Backend: Java, JSP (JavaServer Pages), Servlets

Database: MySQL

Frontend: HTML, CSS, JavaScript

Server: Apache Tomcat
